

A responsive clothes donation matching prototype for charities and donors.

- Charity needs with category, size, quantity, priority, and deadline
- Donor pledge flow with quantity and condition
- 30-minute drop-off slot booking
- Charity arrival tracking
- Donor pledge and impact views
- Local browser persistence
- Donor / charity mode switch


Place the project in XAMPP's `htdocs` folder and open:

`http://localhost/hackathon_project/`

No build step or database is required for the prototype.
